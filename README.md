# PULSE HOP

タップだけでサイバー世界を渡るリズムゲーム。5つの領域・各60拍、約2分22秒の連続した旅です。最初は地面で待つ「ピプ」をタップして即ジャンプ。8拍の無罰練習からフィルを経て本編へ進みます。コンボでモノクロの8bit表現から色・光・奥行きが育ち、ジャンプ・ターン・宙返りも変化します。ミスしても最後まで遊べます。

最終結果に必須300拍のPERFECT・GOOD・MISSを表示します。練習・裏拍は集計しません。全300拍PERFECTでは、通常完走と異なる7色の星型花火と仲間の祝祭・ALL PERFECT表示に。発音数やスコア条件は増やしません。

英数字は本作向けのオリジナル5×7ピクセル字体をローカル配信（WOFF2約1.3KB）。日本語は端末の可読性の高い字体を使います。外部フォントの転載・配信依存はありません。字体の再生成は `tools/pixel_font.py`（開発時のみFontTools／Brotliが必要）。

## ローカル起動

Node.js 20.19以上（または22.12以上）。`npm ci` → `npm run dev`。`npm run build` で型チェックと公開用 `dist/` 生成、`npm run preview` で確認できます。

## 操作

「音を出してスタート」のあと、画面タップ・Space・Enterでジャンプ。練習は得点・コンボに影響せず、タップしなければ自動で跳びません。本編は輪が重なる拍に合わせます。表拍成功後の任意の裏拍で二段ジャンプと波紋（得点追加なし、1拍1回）。裏拍成功で流れ星・UFO・集団ダンサー、トビウオ・忍者・クジラ・気球・ボディビルダー・カンフー・バナナが世界に現れます。最初のゲストと振る舞いはステージで変わり、同時2イベント（ダンサーは1集団）・最長4秒、出現間隔0.9秒以上。同じゲストは重複せず、再試行で掃除します。ダンサーは最低2人、連続する拍で任意裏拍に成功すると最大6人まで増えます。休むと人数が減り、最後の成功から4秒で集団が退場。重複入力では増えません。成績への加算はありません。後半ほど二段ジャンプの軌跡・ポーズ・波紋が華やかになり、コンボと領域の進行を組み合わせて成長します。波紋は最大3個・1.325秒、軌跡は最大6個で次拍の着地まで。PERFECTは弾む文字と光粒、GOODは控えめな弾みで表示。文字は1件だけ、最長0.28秒で消え、連続入力で蓄積しません。♪でミュート、最後に総合結果と再試行。画面を離れると停止し、戻ったら最初から再試行します。「視差効果を減らす」設定では背景を静止、回転・波紋・花火を穏やかにします。

右上のWORLDインジケーターは世界の色づきと同じ7段階（コンボ4・8・12・18・26・36・48）。初期はモノクロ、点灯数と色が増え、MAXで7色が揃います。音の同時発音数を示す表示ではありません。ミスで即リセット、再びコンボで成長します。沿道の仲間は足場と同じ速度で右から左へ流れ、画面外で消えます。世界の成長に合わせ出現密度が増え、同時最大6人。ミス後は最長4秒で静かに減ります。橋渡しだけの応援隊は3人。ダンサー・沿道・応援隊はプレイヤーと共通の丸い体・顔・短い手足を使います。

タイミング補正は±150msで端末内に保存。音に合わせた入力が遅判定になる場合はプラス側へ。Bluetoothより本体スピーカー／有線を推奨。

## 5つの領域と音楽

| 領域 | BPM | 足場／オリジナル曲の特徴 |
|---|---:|---|
| CIRCUIT ROAD | 120 | チップ／C長調の基本ビート |
| DATA TOWERS | 132 | 分岐バス／D長調の跳ねる旋律と刻み |
| LIGHT TUNNEL | 144 | 六角セル／A短調の反復と低音 |
| SIGNAL SEA | 156 | 光パネル／F長調の流れる分散和音 |
| STAR CORE | 168 | 幾何学リング／G長調の高音域と推進力 |

曲は共通の短いモチーフを持ち、各領域で旋律・和声進行・リズムを変えます。4拍の橋渡しが前曲の終止と次曲の導入を兼ね、1拍ずつ3 BPM加速。暗転・途中結果・タイトル画面は挟みません。4拍の橋渡しには応援隊が現れ、次の領域へ送り出します。景色は重なって流れ、着地上面と位置は全領域で統一。舞台の進行とコンボの色彩は独立しています。回路の信号伝播、塔の窓スキャン、トンネルのゲート変形、データ波、コアの軌道組替えが拍に同期。8拍のフレーズで形が変わり、後半にも新しい見せ場が現れます。キャラはステージとフレーズで傾き・ステップ・回転・グライド・ポーズを変えます。画面揺れや全面点滅は使いません。最後だけ、背景のドットと回路の花火で走破を祝います（7発を連続展開、同時最大3発×24点・各1.2秒まで、全画面フラッシュなし）。12拍・約4.3秒のフィナーレで、4拍の盛り上がり→決めの一拍とジャンプ／両手を上げるポーズ→花火の連続展開→余韻に進みます。8拍目・約2.9秒後に総合結果を表示し、いつでも再試行できます。

宙の「光のかけら」は通常ジャンプより高く、二段ジャンプで触れると砕けて波紋へつながります。取らなくても罰や得点差はありません。第1・2領域は各16拍フレーズの16拍目、第3は15拍目、第4は15・16拍目、第5は14〜16拍目に配置。小節基準は各領域の本編1拍目から数え、橋渡しには置きません。

裏拍の見せ場は領域ごとに形・移動・隊形を変えます。波紋はCSSピクセルの共通半径で描き、画面比率による縦伸びを防ぎます。

| 領域 | 現象／機体 | ダンサー隊形 | 波紋 |
|---|---|---|---|
| CIRCUIT ROAD | 階段状に走る信号／横滑りのドット円盤 | 横一列・小刻みステップ | 矩形 |
| DATA TOWERS | 落ちる結晶／斜め降下する菱形機 | 階段状・上下ステップ | 三角 |
| LIGHT TUNNEL | 迫る三角彗星／回転・拡大する六角機 | V字・両手を上げてターン | 六角 |
| SIGNAL SEA | 浮かぶハート泡／波乗りする帆型機 | 波形・揺れるグライド | ハート |
| STAR CORE | 軌道を回る星／リングと衛星の周回機 | 六角の輪・大きなスイング | 星 |

テーマは景色の骨格に使い、飛び入りの内容はナンセンスに振っています。新しい7種はトビウオの弧状跳躍／忍者のダッシュと停止／巨大クジラの横断と潮吹き／気球の上昇／ボディビルダーの両腕ポーズ／カンフーの空中キック／バナナの回転。人型は共通種族です。

出現プールは固定順で、進行と裏拍成功回数から選びます。同じものの連続と同時重複はスキップし、乱数は使いません。各領域のプールは以下。全イベントで同時2枠、出現間隔0.9秒、寿命は最大4秒を維持します。

- 回路：信号・気球・トビウオ・ダンサー・バナナ・UFO・忍者
- 塔：UFO・ボディビルダー・気球・ダンサー・忍者・結晶・バナナ
- トンネル：忍者・カンフー・UFO・ダンサー・トビウオ・バナナ・クジラ
- 海：トビウオ・クジラ・ハート泡・ダンサー・気球・バナナ・UFO
- コア：バナナ・カンフー・UFO・ダンサー・ボディビルダー・クジラ・気球

## 音と判定

矩形波2声＋倍音を補った低音波形1声＋ノイズ1声に固定し、タップ音も既存声の奏法として鳴らします。コンボ0はリズムのみ、4でベース、8で和声、18でメロディー、36・48で豊かな和声／音域。ミスでは旋律3声の未来予約を取消し、30msで減衰。打楽器・曲の時計は継続します。橋渡しでも音層を引き継ぎ、最終花火のために音層を勝手に解放しません。素材・キャラクター・5曲はオリジナルです。

内蔵スピーカー向けに主拍のノイズを800〜約2100Hzへ寄せ、短いアタックを明瞭にします。低音は同じ1声の奇数倍音を補い、高音リードはレベルを55%に抑えて2kHzのローパスで角を丸めます。マスター音量は据え置き。低コンボのタップ音が既存の拍音を上書きしないよう保護します。

すべての拍の時刻を単一のWeb Audio時計上に置き、120ms先まで25msごとに予約します。表拍判定は `min(140ms, 拍長×0.28)`、裏拍は `min(75ms, 拍長×0.15)` で重複しません。最初／各領域のfirst拍はearly入力を優先。重複・キー保持は無効。ジャンプは補正後の次拍までに着地します。
