# PULSE HOP

約30秒、60拍のオリジナルWebリズムゲーム。2小節（8拍）のイントロで拍を掴み、4・3・2・1の合図のあと画面のどこでもタップ。輪が重なる拍に合わせて、小さなキャラクター「ピプ」を足場へ進めます。コンボ4・8・12・18・26・36・48で、モノクロから色・空・光・星へ8段階に進化します。同じ段階でも跳躍・ターン・宙返りなどの動きが変わります。背景はコンボで遠い山・丘・街・手前の景物が増え、速度差と大きさで奥行きを作ります。視差効果を減らす設定では背景スクロールも止めます。ワールドを小さめに表示し、進行方向の足場を数個先まで見渡せます。HUDやボタンの大きさは維持しています。ミスしても最後まで遊べます。

## ローカル起動

Node.js 20.19以上（または22.12以上）。`npm ci` → `npm run dev`。表示されたURLを開きます。`npm run build` で公開用 `dist/` を生成、`npm run preview` で確認できます。

## 操作

「音を出してスタート」で音声を起動。画面タップ、Space、Enterが同じ入力です。表拍成功後の裏拍で任意の二段ジャンプ（追加得点なし、1拍1回）。押さなくても完走でき、次の表拍までに着地します。♪でミュート、終了後は再試行できます。画面を離れると停止し、戻ったら再試行します。端末の「視差効果を減らす」設定では回転・光を抑えます。タイミング補正は±150ms。音に合わせたタップが遅判定になる端末ではプラス側へ調整（端末内に保存）。Bluetoothより本体スピーカー／有線を推奨。

## GitHub Pages

公開先：<https://monnouchi.github.io/demo10/>。Pagesの公開元はGitHub Actionsです。`main` へのpush後、[公開ワークフロー](.github/workflows/pages.yml) が `npm ci` → 型チェック・ビルド → `dist/` のPages公開を行います。PRではビルドのみ実行し、手動実行も可能です。

`src/` がゲーム本体、`dist/` が生成される配信専用成果物、`docs/` が説明書です。`dist/` はcommitしません。初版の `docs/index.html` と `docs/assets/` は削除済みで、ブランチの `/docs` 公開は使用しません。詳しくは[公開手順](docs/deployment.md)。

## 音と判定

120 BPM、2小節の判定なしイントロ（4秒）＋60拍（本編約30秒）＋4拍のアウトロ。終盤の終止フレーズと決めの一拍から、アウトロ中の成績発表へつながります。イントロではキャラクターが拍に合わせて跳ねます。本編最初の拍も従来の±140msで受け付けます。楽曲「Pixel Crossing」、キャラクター、描画は本試作用のオリジナル。外部素材なし。Web Audioの時計で120ms先まで25msごとに予約し、同じ時計で±140msを判定。重複判定と80ms以内の連打は無効。矩形波2声＋三角波1声＋ノイズ1声だけを使い、タップは旋律声の奏法を置き換えます。色や動きが進化しても声数は増えません。オリジナルの2拍リズムを保ち、本編8拍ごとにベースの刻み・音域、打楽器の音色・裏拍・アクセントが累積的に育ちます。音楽の発展は曲の時刻に従い、ミスでは巻き戻りません。和声は冒頭I→IV→ii→V→Iを明確に進み、中盤の転回形・浮遊感、後半の借用iv・掛留・7thから終止へ向かいます。3声の低音と内声を分散し、タップ音もその時の和声に合わせています。コンボ8・18・36・48で7th→9th/掛留→色彩音→高音域の分散へ発展。和声は4拍の境界で一段ずつ切り替わり、ミス直後の急変を避けます。
