# PULSE HOP

約30秒、60拍のオリジナルWebリズムゲーム。2小節（8拍）のイントロから練習タップで拍を掴み、4・3・2・1の合図のあと画面のどこでもタップ。輪が重なる拍に合わせて、小さなキャラクター「ピプ」を足場へ進めます。コンボ4・8・12・18・26・36・48で、モノクロから色・空・光・星へ8段階に進化します。同じ段階でも跳躍・ターン・宙返りなどの動きが変わります。背景はコンボで遠い山・丘・街・手前の景物が増え、速度差と大きさで奥行きを作ります。視差効果を減らす設定では背景スクロールも止めます。ワールドを小さめに表示し、進行方向の足場を数個先まで見渡せます。HUDやボタンの大きさは維持しています。ミスしても最後まで遊べます。

## ローカル起動

Node.js 20.19以上（または22.12以上）。`npm ci` → `npm run dev`。表示されたURLを開きます。`npm run build` で公開用 `dist/` を生成、`npm run preview` で確認できます。

## 操作

「音を出してスタート」で音声を起動。まず地面で待つキャラクターをタップすると即ジャンプし、8拍のイントロが始まります。イントロでも練習タップできます。タップしなければキャラクターは跳びません。音と跳躍で応答しますが、練習は得点・コンボ・音楽の段階に影響しません。最初の本編拍の早め入力は本判定を優先します。画面タップ、Space、Enterが同じ入力です。表拍成功後の裏拍で任意の二段ジャンプ（追加得点なし、1拍1回）。押さなくても完走でき、次の表拍までに着地します。裏拍成功でキャラクターから遠景へ波紋が広がり、コンボで色・広がり・余波が育ちます。最大3個・約1.3秒まで、足場と拍の輪は手前に保ちます。視差効果を減らす設定では広がらない穏やかな輪に切り替えます。♪でミュート、終了後は再試行できます。画面を離れると停止し、戻ったら再試行します。端末の「視差効果を減らす」設定では回転・光を抑えます。タイミング補正は±150ms。音に合わせたタップが遅判定になる端末ではプラス側へ調整（端末内に保存）。Bluetoothより本体スピーカー／有線を推奨。

## GitHub Pages

公開先：<https://monnouchi.github.io/demo10/>。Pagesの公開元はGitHub Actionsです。`main` へのpush後、[公開ワークフロー](.github/workflows/pages.yml) が `npm ci` → 型チェック・ビルド → `dist/` のPages公開を行います。PRではビルドのみ実行し、手動実行も可能です。

`src/` がゲーム本体、`dist/` が生成される配信専用成果物、`docs/` が説明書です。`dist/` はcommitしません。初版の `docs/index.html` と `docs/assets/` は削除済みで、ブランチの `/docs` 公開は使用しません。詳しくは[公開手順](docs/deployment.md)。

## 音と判定

120 BPM、2小節の判定なしイントロ（4秒）＋60拍（本編約30秒）＋4拍のアウトロ。終盤の終止フレーズと決めの一拍から、アウトロ中の成績発表へつながります。イントロではタップした時だけキャラクターが跳ねます。本編最初の拍も従来の±140msで受け付けます。楽曲「Pixel Crossing」、キャラクター、描画は本試作用のオリジナル。外部素材なし。Web Audioの時計で120ms先まで25msごとに予約し、同じ時計で±140msを判定。重複判定と80ms以内の連打は無効。矩形波2声＋三角波1声＋ノイズ1声だけを使い、声数は増えません。開始・コンボ断絶時はリズムのみ。コンボ4でベース、8で和声、18でメロディーが加わり、36・48で色彩音や高音域が育ちます。和声の発展は4拍の境界で反映。ミス時は旋律3声の予約を取り消し、30msで減衰してリズムへ戻ります。曲の時計と打楽器は継続し、再コンボで音楽を育て直せます。イントロは毎拍の聞き取りやすい中音域の打楽器だけ。最後4拍は大きな4・3・2・1と音が一致し、最後の「1」に短い打楽器フィルを添え、その次の拍を強調して最初のタップへつなぎます。フィルの細かい音はタップ不要です。最初のタップから打楽器の開始までは50ms。アウトロも到達したコンボに応じた声だけで締めます。タップ・任意の裏拍は序盤にノイズ声、メロディー解放後に旋律声の短い奏法を使います。オリジナルの2拍リズムを保ち、曲の時刻に応じて打楽器の音色・裏拍・アクセントを変化させます。和声はI→IV→ii→V→I、中盤の転回形、後半の借用iv・掛留から終止へ向かいます。

初版検証：TypeScriptチェック・本番ビルド、Chromeの開始／タップ／ミュート、320px・390px表示。実聴とiPhone実機の音声・遅延は未確認です。
