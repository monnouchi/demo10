# PULSE HOP

タップだけでサイバー世界を渡るリズムゲーム。5つの領域・各60拍、約2分22秒の連続した旅です。最初は地面で待つ「ピプ」をタップして即ジャンプ。8拍の無罰練習からフィルを経て本編へ進みます。コンボでモノクロの8bit表現から色・光・奥行きが育ち、ジャンプ・ターン・宙返りも変化します。ミスしても最後まで遊べます。

## ローカル起動

Node.js 20.19以上（または22.12以上）。`npm ci` → `npm run dev`。`npm run build` で型チェックと公開用 `dist/` 生成、`npm run preview` で確認できます。

## 操作

「音を出してスタート」のあと、画面タップ・Space・Enterでジャンプ。練習は得点・コンボに影響せず、タップしなければ自動で跳びません。本編は輪が重なる拍に合わせます。表拍成功後の任意の裏拍で二段ジャンプと波紋（得点追加なし、1拍1回）。後半ほど二段ジャンプの軌跡・ポーズ・波紋が華やかになり、コンボと領域の進行を組み合わせて成長します。波紋は最大3個・1.325秒、軌跡は最大6個で次拍の着地まで。PERFECTは弾む文字と光粒、GOODは控えめな弾みで表示。文字は1件だけ、最長0.28秒で消え、連続入力で蓄積しません。♪でミュート、最後に総合結果と再試行。画面を離れると停止し、戻ったら最初から再試行します。「視差効果を減らす」設定では背景を静止、回転・波紋・花火を穏やかにします。

タイミング補正は±150msで端末内に保存。音に合わせた入力が遅判定になる場合はプラス側へ。Bluetoothより本体スピーカー／有線を推奨。

## 5つの領域と音楽

| 領域 | BPM | 足場／オリジナル曲の特徴 |
|---|---:|---|
| CIRCUIT ROAD | 120 | チップ／C長調の基本ビート |
| DATA TOWERS | 132 | 分岐バス／D長調の跳ねる旋律と刻み |
| LIGHT TUNNEL | 144 | 六角セル／A短調の反復と低音 |
| SIGNAL SEA | 156 | 光パネル／F長調の流れる分散和音 |
| STAR CORE | 168 | 幾何学リング／G長調の高音域と推進力 |

曲は共通の短いモチーフを持ち、各領域で旋律・和声進行・リズムを変えます。4拍の橋渡しが前曲の終止と次曲の導入を兼ね、1拍ずつ3 BPM加速。暗転・途中結果・タイトル画面は挟みません。景色は重なって流れ、着地上面と位置は全領域で統一。舞台の進行とコンボの色彩は独立しています。最後だけ、背景のドットと回路の花火で走破を祝います（7発を連続展開、同時最大3発×24点・各1.2秒まで、全画面フラッシュなし）。12拍・約4.3秒のフィナーレで、4拍の盛り上がり→決めの一拍とジャンプ／両手を上げるポーズ→花火の連続展開→余韻に進みます。8拍目・約2.9秒後に総合結果を表示し、いつでも再試行できます。

## 音と判定

矩形波2声＋三角波1声＋ノイズ1声に固定し、タップ音も既存声の奏法として鳴らします。コンボ0はリズムのみ、4でベース、8で和声、18でメロディー、36・48で豊かな和声／音域。ミスでは旋律3声の未来予約を取消し、30msで減衰。打楽器・曲の時計は継続します。橋渡しでも音層を引き継ぎ、最終花火のために音層を勝手に解放しません。素材・キャラクター・5曲はオリジナルです。

すべての拍の時刻を単一のWeb Audio時計上に置き、120ms先まで25msごとに予約します。表拍判定は `min(140ms, 拍長×0.28)`、裏拍は `min(75ms, 拍長×0.15)` で重複しません。最初／各領域のfirst拍はearly入力を優先。重複・キー保持は無効。ジャンプは補正後の次拍までに着地します。

## GitHub Pages

公開先：<https://monnouchi.github.io/demo10/>。公開元はGitHub Actions。`main` のpush後に[公開ワークフロー](.github/workflows/pages.yml)がビルドして `dist/` を配信します。PRはビルドのみ、手動実行も可能。`dist/` はcommitしません。詳しくは[公開手順](docs/deployment.md)。

検証ではChrome純正PCMとブラウザ操作を使います。実行環境の通常スピーカー出力で独立音声テストの時計も停止する場合は、出力先なしのChrome音声時計で確認し、実聴とは区別します。iPhone実機の音・遅延は未確認です。
